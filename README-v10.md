# IR Universal 4.0 — Build 10

Esta versión añade:

- Biblioteca IR online con búsqueda por marca y modelo.
- Fuentes: Flipper-IRDB comunitaria, catálogo oficial de Flipper Devices e IRDB.
- Búsqueda profunda para marcas/modelos poco comunes.
- Importación directa desde una URL HTTPS de archivos .ir o CSV IRDB.
- Prueba de botones antes de guardar.
- Guardado de mandos completos para uso offline en «Mis equipos».
- Comprobador de compatibilidad del accesorio para transmisión y aprendizaje.
- La función Aprender bloquea capturas si iOS solo detecta el micrófono interno.
- Selector de icono de la app con cuatro diseños.
- Los iconos se generan durante la compilación para mantener el repositorio ligero.

La transmisión IR existente y el orden de barrido conocido se conservan.
